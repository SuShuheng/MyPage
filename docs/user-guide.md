# MyPage 用户指南

## 第一次打开

启用插件后，MyPage 会打开首次引导并询问是否在 Obsidian 启动后自动打开。
选择只写入 `data.json`，以后可在设置中修改。功能区图标和命令面板均可打开主页。

## 主页和编辑会话

顶部 TAB 对应多个命名主页。拖动 TAB 可排序；右键可重命名、复制、设为默认、
移动、隐藏或删除。

默认是查看模式，组件只响应点击、筛选、打开笔记和受控动作。点击“编辑”后才可：

- 拖动和缩放组件；
- 撤销或重做；
- 添加默认、官方、第三方或已导入模块的组件；
- 新建分组并把组件移入或移出分组；
- 从组件菜单修改数据范围、显示简繁、外观和配置 JSON。

“完成”把整个编辑会话原子写入 `data.json`；“取消”丢弃主页变化，但不会卸载
编辑期间安装的模块。

## 每组件数据范围

每个组件都有独立的包含文件夹、排除文件夹、扩展名、标签、Frontmatter 条件、
时间范围、查询、聚合、排序和字段映射。`/` 表示当前 Vault 根目录。修改一个
组件的范围不会改变其他组件。

内置数据源：

- `core.vault-files`：笔记、Frontmatter、标签、链接和时间戳；
- `core.tasks`：Markdown 任务；
- Bases 适配器：把支持的 `.base` 筛选和排序翻译为统一查询。

## 模块和市场

官方市场在打开市场页面时后台检测更新。第三方市场必须由用户添加公开
`owner/repo`，并且只在用户点击“手动检测”时访问。独立 ZIP 与本地模块不会自动
检测更新。

模块安装后默认处于沙箱。进入“设置 → DIY 模块与市场 → 权限与信任”可查看：

1. 运行信任层级；
2. 每项声明能力和原因；
3. 当前设备、当前 Vault、当前版本的精确作用域；
4. 授权与撤销按钮。

官方来源不会自动授权，也不会自动提升到受信任。

## 蓝图

命令“导出当前主页蓝图”会在 Vault 中创建 `.mypage.json`。蓝图包含布局、组件
实例、数据绑定、主题覆盖和模块依赖，不包含可执行代码、权限或密钥。导入前会
预览缺失模块并要求重新绑定设备绝对路径。

## 更新和恢复

默认使用稳定通道；预览通道可接收 beta/rc。每个 Obsidian 会话启动检测最多
一次，也可手动检测。桌面端可确认后一键更新，下载资产会先校验 SHA-256，再备份
和原子替换；失败自动回滚。移动端只提供 Release 页面。

每次正式配置写入前会在 `backups/` 创建有限副本。设置页可选择恢复。安全模式
不会运行 DIY 模块，但保留所有主页和安装记录。
