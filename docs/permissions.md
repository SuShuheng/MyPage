# 权限与双层信任

MyPage 将“能否运行高风险能力”和“具体能访问什么”拆为两层：

1. 信任层级：`sandbox` 或用户显式选择的 `trusted`；
2. 能力授权：每项 capability 的精确 scope。

安装来源、manifest 的 `trust` 声明和官方身份都不能替用户完成第一层或第二层。
所有安装始终从 `sandbox` 开始。降级回沙箱会立即撤销高风险授权。

能力包括 Vault 读写、网络、外部文件读写、Git 读写、Obsidian 命令和系统执行。
外部文件、Git、Vault 写入、命令及系统执行属于高风险能力，沙箱不可申请。

授权绑定：

- 模块 ID 和精确版本；
- 当前 Vault ID；
- 当前设备 ID；
- capability；
- 文件夹、协议/域名/端口、仓库、命令或可执行文件精确范围。

模块升级若权限声明哈希改变，会撤销旧授权。外部路径和 Git 仓库在解析真实路径后
再次匹配，防止符号链接逃逸。网络重定向默认拒绝，响应大小和超时受限。进程使用
参数数组调用，不经过 shell。
